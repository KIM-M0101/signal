# README.md

1. 프로젝트 이름

시그널 하우스

2. 한 줄 소개

내가 처음 설정한 두 캐릭터와 각자의 1:1 AI 채팅에서 오늘의 작은 성취와 일상 이야기를 나누는 서비스입니다.

3. 해결하려는 문제

자존감이 낮거나 기분이 가라앉고 불안할 때는 일상에서 해낸 작은 일도 쉽게 지나치게 됩니다. 그런 사용자가 부담 없이 하루를 기록하고, 좋아하는 캐릭터의 반응을 통해 자신의 노력을 돌아볼 수 있도록 돕습니다. 서비스가 심리 진단·치료·상담을 제공하는 것은 아닙니다.

4. 주요 사용자

학생 사용자를 포함한 청소년과 성인입니다. 특히 미성년자의 개인정보 보호를 우선합니다. 작은 성취를 기록하고 응원을 받고 싶은 사용자를 대상으로 합니다.

5. MVP 범위

만들 기능

- 시그널 대상 설정 화면에서 캐릭터별 사진 또는 아바타, 이름, 사용자 기준 관계(동갑·연상·연하), 호칭을 설정하고 편집합니다. 사진 업로드는 선택 사항이며 기본 아바타를 제공합니다.
- 두 캐릭터의 말투를 고르고, 성격이나 듣고 싶은 표현을 직접 적을 수 있습니다.
- 처음 설정을 마치면 각 캐릭터의 첫 인사가 채팅 목록에 표시됩니다. 목록에서 최근 메시지와 읽지 않은 답장을 확인합니다.
- 대화 목록에서 한 캐릭터를 선택하면 1:1 채팅방에서 여러 턴의 AI 답장을 받을 수 있습니다. 최근 메시지를 방별로 구분해 답장에 사용합니다.
- 답장을 준비하는 동안 상태를 표시합니다. 연결이 끊기거나 응답이 실패해도 보낸 메시지가 남아 있어 같은 자리에서 다시 답장을 받을 수 있습니다. 위험 신호에는 안전 안내를 우선합니다.
- 보관함에서 새 채팅 기록과 이전 버전의 기록을 날짜별로 확인합니다. 설정에서 대화 기록 또는 캐릭터와 대화를 삭제할 수 있습니다.
- ‘오늘의 시그널’ 화면은 비활성화하고 잠금 이유를 안내합니다. 받은 시그널은 보관함에서 모아보고, 항목이 없을 때는 빈 상태를 보여줍니다.
- 프로토타입은 실제 학생 사진, 학번, 연락처 등 불필요한 식별 정보를 수집·보관하지 않습니다.

만들지 않을 기능

호감도·관계 점수와 변화 연출, 오늘의 시그널 활성 발송·밤 10시 발송·추리 공개, 4명을 초과하는 캐릭터, 복잡한 스토리 분기, 실제 사용자 간 매칭·채팅, 음성 대화, 결제·광고, 심리 진단·치료 기능은 MVP 범위에서 제외합니다.

6. 실행 방법

Expo SDK 57과 React Native로 모바일 앱을 구현했습니다. Node.js 24가 설치된 환경에서 프로젝트 폴더를 열고 의존성을 설치합니다.

```sh
npm ci
```

Windows x64에서는 로컬 AI 실행 파일과 약 1.12GB 모델을 한 번 내려받습니다. 공식 배포 파일의 체크섬을 검사하고 `.local-ai/`에 보관합니다.

```sh
npm run ai:setup:windows
npm run ai:serve:windows
```

위 모델 서버를 켜둔 상태에서 다른 터미널에 아래 명령을 실행하고 브라우저에서 http://127.0.0.1:8081/ 을 엽니다.

```sh
npm run web
```

이미 웹을 빌드했다면 `npm run serve:web`로 다시 열 수 있습니다. 모델 서버는 `127.0.0.1:8083`을 사용합니다. 다른 운영체제에서 테스트할 때는 [llama.cpp 공식 배포본](https://github.com/ggml-org/llama.cpp/releases)으로 같은 모델을 `--alias signal-local --host 127.0.0.1 --port 8083` 옵션에 맞춰 실행할 수 있습니다.

모바일 실기기에서는 모델 서버를 개발 PC에 켜두고, 앱 서버를 PC의 사설 IP에 바인딩합니다. Windows PowerShell 예시는 다음과 같습니다. `192.168.0.10`을 테스트하는 PC의 실제 사설 IP로 바꿉니다.

```powershell
$env:SIGNAL_HOST='192.168.0.10'
npm run serve:web
```

별도 터미널에서 앱이 접속할 주소를 지정한 뒤 `npm start`를 실행합니다. Expo 개발 서버는 8082번 포트를 사용합니다. 같은 네트워크에 연결된 기기의 SDK 57 Expo Go에서 QR 코드를 엽니다.

```powershell
$env:EXPO_PUBLIC_SIGNAL_API_URL='http://192.168.0.10:8081'
npm start
```

```sh
npm test
npm run build:web
```

시연 흐름은 소개 → 캐릭터 2명 설정 → 첫 인사 확인 → 1:1 채팅입니다. 같은 방에서 두 번째 메시지를 보내고, 다른 캐릭터 방으로 바꾼 뒤 새로고침해 방별로 대화가 복원되는지 확인합니다. 보관함에서 대화 기록과 답장을 다시 볼 수 있습니다. 설정의 ‘시그널 후속안 미리보기’는 합성 예시로만 잠금, 추리와 편지를 살펴보는 화면입니다.

대화와 캐릭터 설정은 사용하는 기기나 브라우저에 직접 삭제할 때까지 보관합니다. 답장은 개발 PC의 Qwen 로컬 모델에서 생성합니다. 채팅 요청에는 선택한 캐릭터의 텍스트 설정과 같은 방의 최근 메시지만 포함하고, 이미지는 모델로 보내지 않습니다. 외부 모델 연결, 운영 보관 기간과 안전 안내 기준은 팀에서 별도로 결정합니다.

7. 현재 파일 목록

- `README.md`: 프로젝트 소개, MVP 범위, 진행할 작업을 정리한 문서
- `PRD.md`: 문제 정의, 사용자 흐름, MVP 요구사항, 안전·개인정보 고려사항을 정리한 제품 요구사항 문서
- `AGENTS.md`: 작업 원칙, 개인정보 보호, 범위 제한 및 AI 응답 지침
- `App.js`, `index.js`: Expo 앱 화면과 시작 지점
- `src/`: 모바일 화면과 테마, 캐릭터와 방별 대화 데이터, 로컬 AI 요청, 기본 아바타
- `server/`: 웹 미리보기와 로컬 모델 연결
- `tests/`: 대화 맥락 분리, 모델 요청·실패·위험 신호, 이전 기록 호환 검증
