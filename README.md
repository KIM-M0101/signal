# README.md

1. 프로젝트 이름

시그널 하우스

2. 한 줄 소개

오늘 해낸 작은 일을 기록하면 내가 설정한 두 캐릭터가 칭찬과 응원을 보내고, 기록을 다시 돌아볼 수 있게 돕는 서비스입니다.

3. 해결하려는 문제

자존감이 낮거나 기분이 가라앉고 불안할 때는 일상에서 해낸 작은 일도 쉽게 지나치게 됩니다. 그런 사용자가 부담 없이 하루를 기록하고, 좋아하는 캐릭터의 반응을 통해 자신의 노력을 돌아볼 수 있도록 돕습니다. 서비스가 심리 진단·치료·상담을 제공하는 것은 아닙니다.

4. 주요 사용자

학생 사용자를 포함한 청소년과 성인입니다. 특히 미성년자의 개인정보 보호를 우선합니다. 작은 성취를 기록하고 응원을 받고 싶은 사용자를 대상으로 합니다.

5. MVP 범위

만들 기능

- 시그널 대상 설정 화면에서 캐릭터별 사진 또는 아바타, 이름, 사용자 기준 관계(동갑·연상·연하), 호칭을 설정하고 편집합니다. 사진 업로드는 선택 사항이며 기본 아바타를 제공합니다.
- 2명의 캐릭터 각각 이름, 성격, 말투, 반응 예시를 개별 정의합니다.
- 사용자가 하루의 작은 성취나 이야기를 기록하면 캐릭터들이 서로 구분되는 말투와 반응 방향으로 구체적인 칭찬과 응원을 보냅니다. 기록에 없는 사실을 꾸며 칭찬하거나 사용자를 평가·비교하지 않습니다.
- AI 응답은 기록 후 5초 안에 표시되는 것을 목표로 합니다. 생성 실패나 시간 초과 시 기본 문구를 표시하며, 위험 신호가 포함된 기록에는 일반 칭찬보다 사전 검토된 안전 안내를 우선합니다.
- 기록과 캐릭터 반응을 다시 확인할 수 있습니다.
- ‘오늘의 시그널’ 화면은 비활성화하고 잠금 이유를 안내합니다. 받은 시그널은 보관함에서 모아보고, 항목이 없을 때는 빈 상태를 보여줍니다.
- 프로토타입은 실제 학생 사진, 학번, 연락처 등 불필요한 식별 정보를 수집·보관하지 않습니다.

만들지 않을 기능

호감도·관계 점수와 변화 연출, 오늘의 시그널 활성 발송·밤 10시 발송·추리 공개, 4명을 초과하는 캐릭터, 복잡한 스토리 분기, 실제 사용자 간 매칭·채팅, 음성 대화, 결제·광고, 심리 진단·치료 기능은 MVP 범위에서 제외합니다.

6. 실행 방법

Expo SDK 57과 React Native로 모바일 앱을 구현했습니다. Node.js 24가 설치된 환경에서 프로젝트 폴더를 열고 의존성을 설치합니다.

```sh
npm ci
```

웹에서는 아래 명령을 실행하고 브라우저에서 http://127.0.0.1:8081/ 을 엽니다.

```sh
npm run web
```

모바일에서는 `npm start`를 실행하고 SDK 57을 지원하는 Expo Go에서 QR 코드를 엽니다. 테스트 기기와 개발 PC를 같은 네트워크에 연결해 주세요.

```sh
npm test
npm run build:web
```

시연 흐름은 소개 → 캐릭터 2명 설정 → 오늘의 이야기 기록 → 두 응원 확인 → 기록 다시 보기입니다. 시그널 메뉴에서는 잠금 안내와 빈 보관함을 확인할 수 있습니다. 캐릭터 이미지 선택은 합성 테스트 이미지로 체험합니다.

이 프로토타입은 기록과 캐릭터 설정을 이 기기 또는 브라우저에 직접 삭제할 때까지 보관합니다. 답장은 기기 안의 준비 문구를 사용합니다. 외부 AI 연결, 기록의 장기 기억과 운영 보관 기간은 팀에서 별도로 결정합니다.
