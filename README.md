# README.md

1. 프로젝트 이름

하루시그널 (저장소 이름: signal)

2. 한 줄 소개

하루의 이야기를 남기면, 내가 설정한 두 캐릭터가 응원하고 밤 10시에 시그널을 보내는 서비스입니다.

3. 해결하려는 문제

자존감이 낮거나 기분이 가라앉고 불안할 때는 일상에서 해낸 작은 일도 쉽게 지나치게 됩니다. 그런 사용자가 부담 없이 하루를 기록하고, 좋아하는 캐릭터의 반응을 통해 자신의 노력을 돌아볼 수 있도록 돕습니다. 서비스가 심리 진단·치료·상담을 제공하는 것은 아닙니다.

4. 주요 사용자

학생 사용자를 포함한 청소년과 성인입니다. 미성년자의 개인정보 보호를 우선합니다.

5. 기능 범위

화면과 흐름은 `SCREEN_SPEC.md`, `USER_FLOW.md`, 세부 규칙은 `PRD.md`를 기준으로 합니다.

- 첫 진입(바로 시작하기·로그인·개인정보 안내, 설정 중 이어하기)과 이 기기 계정 로그인
- 온보딩 3단계: 내 프로필(닉네임 필수) → 캐릭터 2명(필수 항목 + 말투 미리보기, 추가 설정은 접기) → 계정 만들기 또는 계정 없이 시작하기(나중에 설정에서 계정 추가)
- 우리 채팅방: 오늘 카드(일기 상태·시그널 도착까지 남은 시간), 캐릭터 카드(호감도 단계·진행 바·%, 한 줄 상태), 1:1 AI 채팅, 일기 응원 카드
- 오늘의 일기: 감정 이모지와 감정별 질문, 하루 한 번, 당일 수정·삭제(⋯ 메뉴), 오늘의 한마디와 두 캐릭터 응원이 차례로 도착
- 시그널: 일기를 쓴 날은 일기로, 일기 없이 대화만 한 날은 그날 대화로 밤 10시 도착(기기 알림, 시연 버튼), 별이 반짝이는 밤하늘 보관함, 봉투 열기, 말투로 발신자 추측, 맞히면 하트 효과
- 화면: 설정 → 화면에서 배경색 5가지(연보라·크림·연분홍·하늘·민트) 선택
- 대화 품질: 반말/존댓말이 섞이거나 일본어·한자가 나오면 서버가 다시 쓰게 하고, 남으면 지운 뒤 보여줌
- 설정: 프로필·캐릭터 수정·삭제, 기록 삭제, 계정 삭제, 로그아웃

6. 실행 방법

**팀원 빠른 시작 (Windows):** Git과 Node.js 24를 설치하고 `git clone https://github.com/KIM-M0101/signal.git` 한 뒤, `signal` 폴더의 `start-harusignal.bat`를 더블클릭하면 패키지 설치, 로컬 AI 준비, 서버 실행, 브라우저 열기까지 한 번에 됩니다. 자세한 방법과 문제 해결은 [`TEAM_SETUP.md`](TEAM_SETUP.md)를 보세요.

Expo SDK 57과 React Native로 모바일 앱을 구현했습니다. Node.js 24가 설치된 환경에서 프로젝트 폴더를 열고 의존성을 설치합니다.

```sh
npm ci
```

Windows x64에서는 로컬 AI 실행 파일과 약 1.12GB 모델을 한 번 내려받습니다. 공식 배포 파일의 체크섬을 검사하고 `.local-ai/`에 보관합니다.

```sh
npm run ai:setup:windows
npm run ai:serve:windows
```

위 모델 서버를 켜둔 상태에서 다른 터미널에 아래 명령을 실행하고 브라우저에서 http://127.0.0.1:8081/ 을 엽니다.

```sh
npm run web
```

이미 웹을 빌드했다면 `npm run serve:web`로 다시 열 수 있습니다. 모델 서버는 `127.0.0.1:8083`을 사용합니다. 다른 운영체제에서 테스트할 때는 [llama.cpp 공식 배포본](https://github.com/ggml-org/llama.cpp/releases)으로 같은 모델을 `--alias signal-local --host 127.0.0.1 --port 8083` 옵션에 맞춰 실행할 수 있습니다.

모바일 실기기에서는 모델 서버를 개발 PC에 켜두고, 앱 서버를 PC의 사설 IP에 바인딩합니다. Windows PowerShell 예시는 다음과 같습니다. `192.168.0.10`을 테스트하는 PC의 실제 사설 IP로 바꿉니다.

```powershell
$env:SIGNAL_HOST='192.168.0.10'
npm run serve:web
```

별도 터미널에서 앱이 접속할 주소를 지정한 뒤 `npm start`를 실행합니다. Expo 개발 서버는 8082번 포트를 사용합니다. 같은 네트워크에 연결된 기기의 SDK 57 Expo Go에서 QR 코드를 엽니다.

```powershell
$env:EXPO_PUBLIC_SIGNAL_API_URL='http://192.168.0.10:8081'
npm start
```

```sh
npm test
npm run build:web
```

시연 흐름은 바로 시작하기 → 내 프로필 → 캐릭터 2명 설정 → 계정 만들기(또는 계정 없이 시작하기) → 우리 채팅방 → 1:1 채팅 → 오늘의 일기 → AI 총평·응원 → 시그널 보관함의 ‘밤 10시 도착 테스트’ → 시그널 열기 → 발신자 추측입니다. 일기 한 건에 AI 호출 세 번(총평, 캐릭터 응원 두 개), 시그널 한 통에 한 번이 듭니다. 시그널 생성이 실패하면 일기(없으면 그날 대화)를 반영한 기본 편지로 도착합니다.

계정, 프로필, 일기와 대화는 사용하는 기기나 브라우저에 직접 삭제할 때까지 보관합니다. 기본 모드의 답장은 개발 PC의 Qwen 로컬 모델에서 생성합니다. AI 요청에는 내 프로필과 캐릭터의 텍스트 설정, 해당 일기 또는 같은 방의 최근 메시지만 포함하고, 사진과 비밀번호는 보내지 않습니다.

### 베이즈 GPT-6 Luna 테스트

학교 계정으로 팀 프로젝트용 API 사용이 허용된 경우 이 PC에서 가상의 이름과 대화로 테스트합니다. 프로젝트 루트의 `.env.baze.local` 파일에 `BAZE_API_KEY=` 한 줄을 만들고 등호 뒤에 새 키를 입력합니다. 이 파일은 Git에서 제외됩니다. 아래 명령을 실행한 뒤 http://127.0.0.1:8084/ 를 엽니다.

```powershell
npm.cmd run build:web
npm.cmd run serve:baze
```

8084번 테스트에서는 동의한 뒤 같은 방의 최근 메시지와 캐릭터의 텍스트 설정으로 베이즈의 GPT-6 Luna가 답장을 생성합니다. 안전 안내로 처리된 대화 차례와 이미지는 베이즈 요청에서 제외합니다. 8084번 브라우저 저장소에는 테스트 캐릭터와 대화가 별도로 저장되고, 8081번은 기본 로컬 모드입니다. 토큰 사용량은 답장 후 화면에 표시되며 실제 차감은 Gateway 사용량에서 확인합니다. 실제 학생이 사용할 환경의 데이터 전송·보관 조건과 안전 안내 기준은 별도로 확정합니다.

### 베이즈 모델 비교

학교 계정으로 팀 프로젝트용 API 사용이 허용된 경우, Windows PowerShell에서 합성 대화로 GPT-6 Luna와 Solar Mini 4를 비교합니다.

```powershell
Set-Location E:\proj\signal
npm.cmd run ai:compare:baze
```

숨김 입력창에 새 API 키를 입력하면 고정된 합성 사례 6개를 모델별로 한 번씩 호출합니다. 답장과 입력·출력 토큰, 응답 시간, 공개 단가 기준 예상 크레딧을 표시합니다. 실제 차감액은 베이즈 Gateway의 사용량에서 확인합니다. 이 명령은 앱의 저장된 대화와 분리해서 실행합니다.

7. 현재 파일 목록

- `README.md`: 프로젝트 소개와 실행 방법
- `TEAM_SETUP.md`: 팀원용 실행 가이드, `start-harusignal.bat`: Windows 더블클릭 실행
- `SCREEN_SPEC.md`, `USER_FLOW.md`: 화면 명세와 사용자 흐름
- `PRD.md`: 목표, 범위 결정(계정·호감도·시그널 규칙), 안전 원칙
- `AGENTS.md`: 작업 원칙, 개인정보 보호, 범위 제한 및 AI 응답 지침
- `App.js`, `index.js`: 화면 이동과 상태 관리, 시작 지점
- `src/model.js`: 계정, 프로필, 채팅, 일기, 호감도, 시그널 규칙과 저장 데이터
- `src/screens.js`, `src/theme.js`, `src/art.js`: 화면 컴포넌트, 스타일, 기본 아바타
- `src/chat-api.js`: 채팅·일기·시그널 AI 요청, `src/sha256.js`: 비밀번호 해시, `src/notify.js`: 밤 10시 로컬 알림
- `assets/fonts/`: Pretendard 글꼴(SIL Open Font License, `Pretendard-LICENSE.txt`)
- `server/`: 웹 미리보기와 로컬 모델·베이즈 연결 (`/api/chat`, `/api/diary`, `/api/signal`)
- `tests/`: 계정·일기·호감도·시그널 규칙과 서버 요청 검증
